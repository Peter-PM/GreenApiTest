# Green API — MAX

Прототип интерфейса для отправки и получения **текстовых** сообщений в мессенджере MAX через шлюз [GREEN-API](https://green-api.com/max). Внешний вид — по мотивам [web.max.ru](https://web.max.ru/).

Документация API: <https://green-api.com/v3/docs/api/>

Онлайн-сборка: <https://peter-pm.github.io/GreenApiTest/> — публикуется из этого репозитория, собирается в CI.

## Что нужно

- Node 22 и npm
- аккаунт GREEN-API с авторизованным инстансом MAX

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:5173. Файл `.env.local` не нужен: учётные данные вводятся на экране входа и живут только в памяти вкладки.

## Как пользоваться

1. На экране входа ввести два значения из личного кабинета GREEN-API: **idInstance** (номер инстанса) и **apiTokenInstance** (ключ доступа).
2. Нажать **«Новый чат»**, ввести номер телефона получателя (11–12 цифр, код 7 или 375) и нажать **«Создать»** — приложение вызовет `checkAccount` и получит `chatId`.
3. Написать сообщение и отправить — уходит `sendMessage`.
4. Ответ появится в чате сам: приложение висит на очереди `receiveNotification` и разбирает входящие.

## Хост API

Хост зашит в коде — константа `API_HOST` в `src/api/greenApi.ts`, сейчас это `https://3100.api.green-api.com`.

## Если входящие не приходят

Проверьте, что в кабинете GREEN-API **не задан** `webhookUrl`: с ним приём сообщений не работает, API отдаёт ошибку про custom webhook url. Сбросьте его и подождите около минуты.
